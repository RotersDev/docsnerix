Os webhooks enviam um `POST` em JSON para o seu servidor sempre que algo importante acontece na loja. Use para liberar acesso, integrar com ERP ou CRM, ou automatizar fluxos.

## Como configurar

<Steps>
  <Step title="Abra os webhooks">
    No painel da loja, vá em **Configurações → Integrações → Webhooks**.
  </Step>
  <Step title="Cadastre a URL">
    Clique em **Novo webhook** e informe a URL `https` do seu servidor (ex.: `https://seu-servidor.com/webhooks/nerix`).
  </Step>
  <Step title="Escolha os eventos">
    Por padrão vêm marcados **Venda gerada** (`order.created`) e **Venda aprovada** (`order.approved`).
  </Step>
  <Step title="Guarde o segredo">
    Ao salvar, o painel mostra o segredo `whsec_...` **uma única vez**. Use-o para validar a assinatura.
  </Step>
</Steps>

<Tip>
  Use **Testar** no webhook para receber um evento `ping` e conferir a integração antes de vender.
</Tip>

## Eventos

| Evento | Quando é enviado |
|:---|:---|
| `order.created` | Um pedido é criado no checkout (ainda não pago). |
| `order.approved` | O pagamento do pedido foi confirmado (Pix, cartão ou cripto). **Use este para liberar o pedido.** |
| `order.cancelled` | O pedido foi cancelado ou expirou sem pagamento. |
| `order.refunded` | O pedido foi reembolsado ou contestado. |
| `product.stock_depleted` | Um produto ficou sem estoque disponível. |
| `customer.created` | Um cliente novo se cadastrou na loja. |
| `review.created` | Uma avaliação nova foi enviada. |
| `subscription.activated` | Uma assinatura foi ativada. |
| `subscription.renewed` | Uma assinatura foi renovada (cobrança paga). |
| `subscription.overdue` | A cobrança da assinatura venceu sem pagamento. |
| `subscription.suspended` | A assinatura foi suspensa por falta de pagamento. |
| `subscription.reactivated` | Uma assinatura suspensa voltou a ficar ativa. |
| `subscription.cancelled` | A assinatura foi cancelada. |
| `payment_link.paid` | Um [link de pagamento](/links-de-pagamento/visao-geral) recebeu um pagamento confirmado. |
| `payment_link.refunded` | Um pagamento de link de pagamento foi reembolsado ou contestado. |


## Formato de toda entrega

Todos os eventos usam o mesmo envelope. O conteúdo de cada evento fica em `data`.

```json
{
  "id": "evt_10482",
  "type": "order.approved",
  "created_at": "2026-10-30T03:18:53.004Z",
  "data": { }
}
```

| Campo | Descrição |
|:---|:---|
| `id` | ID único da entrega (`evt_...`). Use para não processar a mesma entrega duas vezes. |
| `type` | Nome do evento. |
| `created_at` | Momento do envio, em ISO 8601 (UTC). |
| `data` | Conteúdo do evento (exemplos abaixo). |

Valores em dinheiro dos pedidos vêm como texto em reais (ex.: `"59.80"`).

## Headers

| Header | Conteúdo |
|:---|:---|
| `Content-Type` | `application/json` |
| `X-Nerix-Event` | Nome do evento (igual a `type`). |
| `X-Nerix-Timestamp` | Momento do envio, em segundos Unix. |
| `X-Nerix-Signature` | `v1=` seguido do HMAC-SHA256 em hexadecimal. |

## Validar a assinatura

Calcule o HMAC-SHA256 de `{X-Nerix-Timestamp}.{corpo bruto}` usando o segredo `whsec_...` e compare com o valor depois de `v1=`. Use o corpo **exatamente como recebido**, antes de converter o JSON.

<CodeGroup>

```js Node.js (Express)
import crypto from 'crypto';
import express from 'express';

const app = express();

app.post('/webhooks/nerix', express.raw({ type: 'application/json' }), (req, res) => {
  const timestamp = req.header('x-nerix-timestamp');
  const received = String(req.header('x-nerix-signature') || '').replace(/^v1=/, '');
  const expected = crypto
    .createHmac('sha256', process.env.NERIX_WEBHOOK_SECRET)
    .update(`${timestamp}.${req.body.toString('utf8')}`)
    .digest('hex');

  const valid = received.length === expected.length
    && crypto.timingSafeEqual(Buffer.from(received), Buffer.from(expected));
  const recent = Math.abs(Date.now() / 1000 - Number(timestamp)) < 300;
  if (!valid || !recent) return res.status(401).end();

  const event = JSON.parse(req.body.toString('utf8'));
  if (event.type === 'order.approved') liberarPedido(event.data.order.order_number);
  res.status(200).end();
});
```

```python Python (Flask)
import hashlib, hmac, os, time
from flask import Flask, request

app = Flask(__name__)

@app.post("/webhooks/nerix")
def nerix_webhook():
    timestamp = request.headers.get("X-Nerix-Timestamp", "0")
    received = request.headers.get("X-Nerix-Signature", "").removeprefix("v1=")
    raw = request.get_data(as_text=True)
    expected = hmac.new(
        os.environ["NERIX_WEBHOOK_SECRET"].encode(),
        f"{timestamp}.{raw}".encode(),
        hashlib.sha256,
    ).hexdigest()
    if not hmac.compare_digest(received, expected) or abs(time.time() - int(timestamp)) > 300:
        return "", 401

    event = request.get_json()
    if event["type"] == "order.approved":
        liberar_pedido(event["data"]["order"]["order_number"])
    return "", 200
```

```php PHP
$raw = file_get_contents('php://input');
$timestamp = $_SERVER['HTTP_X_NERIX_TIMESTAMP'] ?? '0';
$received = preg_replace('/^v1=/', '', $_SERVER['HTTP_X_NERIX_SIGNATURE'] ?? '');
$expected = hash_hmac('sha256', $timestamp . '.' . $raw, getenv('NERIX_WEBHOOK_SECRET'));

if (!hash_equals($expected, $received) || abs(time() - (int) $timestamp) > 300) {
    http_response_code(401);
    exit;
}

$event = json_decode($raw, true);
if ($event['type'] === 'order.approved') {
    liberarPedido($event['data']['order']['order_number']);
}
http_response_code(200);
```

## Entrega e reenvio

- Seu servidor deve responder com qualquer status `2xx` em até **20 segundos**. Processe tarefas demoradas depois de responder.
- Respostas fora de `2xx`, timeout ou redirecionamentos (`3xx`) contam como falha.
- **Não há nova tentativa automática.** Cada entrega fica no histórico do webhook no painel, com status, código HTTP e resposta, e pode ser **reenviada** por lá.
- A URL precisa ser pública. Endereços internos (localhost, IPs privados) são bloqueados.

<Warning>
  Se o seu servidor ficar fora do ar, confira o histórico e reenvie as entregas que falharam. Para não depender só do webhook, você também pode consultar o pedido pela API ([Consultar pedido](/api-reference/orders/get-order)).
</Warning>
