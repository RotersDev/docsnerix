---
title: "Listar Produtos"
api: "GET /api/public/products"
description: "Retorna os produtos da sua loja, com paginação e o estoque de cada produto e variante."
---

Retorna os produtos cadastrados na loja, com o estoque disponível de cada produto e de cada variante. Sem `include_inactive`, só vêm produtos e variantes ativos.

## Paginação

Envie `page` (e, se quiser, `limit`) para receber a resposta paginada no formato `{ data, meta }`. A ordem é sempre a mesma entre as páginas, sem itens repetidos ou pulados.

Para percorrer a loja inteira, comece em `page=1` e avance até `meta.last_page` (ou até `meta.has_more` ser `false`).

O total também vem nos cabeçalhos de toda resposta: `X-Total-Count`, `X-Page`, `X-Per-Page` e `X-Last-Page`.

<Note>
Sem `page` e sem `with_meta`, a resposta é uma lista simples (array) com todos os produtos, como nas versões anteriores da API. Em lojas grandes, prefira paginar.
</Note>

## Parâmetros de Query

<ParamField query="page" type="number">
  Página de resultados, começando em `1`. Com `page`, a resposta vem como `{ data, meta }`.
</ParamField>

<ParamField query="limit" default="20" type="number">
  Itens por página, de `1` a `100`. Valores acima de `100` são reduzidos para `100`. O padrão é `20` quando `page` é enviado.
</ParamField>

<ParamField query="with_meta" default="false" type="boolean">
  Se `true`, responde no formato `{ data, meta }` mesmo sem `page`.
</ParamField>

<ParamField query="include_inactive" default="false" type="boolean">
  Se `true`, inclui produtos e variantes inativos (ocultos na loja). Use o campo `active` para diferenciar. **Requer API Key.**
</ParamField>

<ParamField query="category_id" type="number">
  Filtra produtos pertencentes à categoria correspondente ao ID informado.
</ParamField>

<ParamField query="category_slug" type="string">
  Filtra produtos pelo slug da categoria (ex.: `jogos-pc`).
</ParamField>

<ParamField query="search" type="string">
  Pesquisa produtos pelo nome ou descrição contendo o termo informado. A busca não é paginada: retorna até `limit` itens (padrão `100`) como lista simples e inclui, como itens separados, as variantes cujo nome combina com o termo.
</ParamField>

## Exemplo de Requisição

```bash
curl --request GET \
  --url 'https://api.nerix.com.br/api/public/products?page=1&limit=100&include_inactive=true' \
  --header 'X-nerixkey: SUA_CHAVE_AQUI'
```

## Campos Retornados

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | `number` | ID único do produto. |
| `name` | `string` | Nome do produto. |
| `slug` | `string` | Slug único para URL amigável. |
| `description` | `string` | Descrição do produto (pode conter HTML). |
| `price` | `string` | Preço regular. Em produtos com variantes, o preço fica em cada variante. |
| `promotional_price` | `string \| null` | Preço promocional, se houver. |
| `category_id` | `number \| null` | ID da categoria. |
| `images` | `array` | URLs das imagens. A primeira é a principal. |
| `active` | `boolean` | `false` quando o produto está oculto na loja (só aparece com `include_inactive=true`). `is_active` traz o mesmo valor. |
| `inventory_type` | `string` | `lines` (uma chave por venda), `text` (mesmo conteúdo para todos, com quantidade) ou `file`. |
| `stock` | `number \| null` | Quantidade disponível para venda agora. `null` = estoque infinito; `0` = esgotado. `available_stock` traz o mesmo valor. |
| `stock_limit` | `number \| null` | Estoque configurado. `-1` = infinito. |
| `infinite_stock` | `boolean` | `true` quando o estoque é infinito. |
| `is_variant` | `boolean` | `true` quando o produto tem variantes. Nesse caso, preço e estoque ficam em cada variante. |
| `variants` | `array` | Variantes na ordem da loja, cada uma com `id`, `name`, `price`, `promotional_price`, `active`, `inventory_type`, `stock`, `stock_limit` e `infinite_stock`. |

### Objeto `meta`

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `total` | `number` | Total de produtos que atendem aos filtros. |
| `page` | `number` | Página atual. |
| `limit` | `number` | Itens por página. |
| `last_page` | `number` | Número da última página. |
| `has_more` | `boolean` | `true` enquanto houver próximas páginas. |

## Limite de Requisições

Este endpoint aceita **120 requisições por minuto por API Key**. Ao passar do limite, a resposta é `429 Too Many Requests` com o cabeçalho `Retry-After` (segundos para tentar de novo). Veja [Limites de Requisição](/api-reference/rate-limits).

<Tip>
Para ver as chaves (keys) de estoque de um produto, use [Obter Chaves do Produto](/api-reference/products/get-product-keys).
</Tip>
